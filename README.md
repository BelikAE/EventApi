### Запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/BelikAE/EventApi.git
   cd EventApi

2. Запустите приложение:
	```bash
	dotnet run

После запуска в консоли появятся адреса, по которым доступно API: https://localhost:7179

Откройте браузер и перейдите по адресу https://localhost:7179/swagger для просмотра интерактивной документации Swagger.
